Nexters release smoke test

Production verification for Grid/SDK 2.9.2. This page uses the demo app and production Orb bundle.
Run these probes only after the v2 release and demo testbench are deployed. The Zendesk probe creates one real test ticket; the timeout probes create no customer data.

Customer-facing configuration

Append meya_timeout=6 to the Zendesk webhook Endpoint URL. No BFML change is required:

https://grid.meya.ai/gateway/v2/zendesk_support/APP_ID/INTEGRATION_ID?meya_timeout=6

Use &meya_timeout=6 if the URL already has query parameters. This extends Gateway's incoming wait from five to six seconds; it does not reduce processing time or platform load.

Set comment_author_id on a Zendesk ticket create or update component to attribute that comment to a Zendesk user:

- type: meya.zendesk.support.component.ticket.create
  integration: integration.zendesk.support
  requester_id: (@ flow.author_id )
  subject: Customer support request
  comment: Initial comment
  comment_author_id: (@ flow.author_id )

- type: meya.zendesk.support.component.ticket.update
  integration: integration.zendesk.support
  ticket_id: (@ flow.ticket_id )
  comment: Follow-up comment
  comment_author_id: (@ flow.author_id )

1. URL timeout enforcement

  1. Open the 5.5-second probe. It should return JSON with HTTP 200 after approximately 5.5 seconds.
  2. Open the 6.5-second probe. It should stop at approximately six seconds with HTTP 503.
  3. Both URLs explicitly use meya_timeout=6.
5.5s → expect 200 6.5s → expect 503

2. Zendesk comment author

  1. Run the Zendesk probe once.
  2. Open the reported ticket and verify both comments are attributed to “Meya release smoke author”.
